## 📲 Installation Instructions

* **Coming from v1.1 / v1.2:** Flash `UN1CA_Carbon_IX_1.3_dm1q_GZIF.zip` via TWRP or `adb sideload` (Wipe Cache/Dalvik recommended; dirty flash supported).
